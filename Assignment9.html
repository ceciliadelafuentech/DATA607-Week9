Overview

I will use R to transform the results into a tidy data frame and calculate average daily high temperatures for each period.

Data and transformations

Build the request

# Define the API endpoint
url <- "https://archive-api.open-meteo.com/v1/archive" #url identifies the API endpoint

# Build the API request
request <- request(url) |> #request(url) starts building the request
  req_url_query( #req_url_query() adds the parameters that tell the API what data to retrieve
    latitude = 40.7128,
    longitude = -74.0060,
    start_date = "2025-10-01",
    end_date = "2026-10-26",
    daily = "temperature_2m_max,precipitation_sum", #daily requests the daily maximum temperature and total precipitation
    temperature_unit = "fahrenheit",
    timezone = "America/New_York"
  )

Send the request

# Send the request and retrieve the response
response <- req_perform(request)

# Check the HTTP status code

# Calculate average daily high temperature by year
october_summary <- october_df |>
  mutate(year = format(date, "%Y")) |> #mutate() creates a year column from each date
  group_by(year) |> #group_by(year) separates the observations into 2025 and 2026
  summarise( #summarise() calculates the average daily max temp for each year
    avg_max_temp = round(mean(max_temp), 2),
    .groups = "drop"
  )

Conclusion

The Open-Meteo Historical Weather API provided daily maximum temperatures and total precipitation for New York City. I extracted the nested JSON data into a tibble, and checked column types and missing values. I converted the date column to Date format, and because no missing values were found, no additional cleaning steps were taken.

The analysis found that the average daily maximum temperature from October 1–26 was 67.87°F in2026, compared with 66.53°F in 2025, a difference of approximately 1.34°F. The line graph showed daily temperature fluctuations in both years, but temperatures in 2026 generally remained higher after around October 10, while temperatures in 2025 declined and did not return to their earlier highs.

Future improvements could include automating the date range so the code retrieves data through the current month and day, reducing the need for manual updates. The analysis could also be expanded to include additional years to provide more context on whether these temperature differences are unusual.
